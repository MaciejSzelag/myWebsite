## 📌 About The Project

Welcome to the official repository of my web development portfolio and personal website!

This project serves three core purposes:

1. **Developer Portfolio** – Showcasing my coding skills, clean architecture approach, and completed projects.
2. **Client Services Hub** – A business card for prospective clients looking for fast, bespoke, modern websites and web solutions.
3. **Tech & Development Blog** – A space where I share programming insights, web development tutorials, and updates on projects I'm actively building.

Built from scratch using **pure (Vanilla) PHP** — free from bloated third-party frameworks to maintain maximum speed, complete control over the codebase, and top-tier performance.

---

## ✨ Features

- [x] **Modern Landing Page** – Engaging presentation of my skills, services, and profile.
- [x] **Portfolio Showcase** – Interactive presentation of past client work and personal projects.
- [x] **Integrated Blog** – Lightweight, custom publishing system for articles and tech guides.
- [x] **Fully Responsive (RWD)** – Pixel-perfect experience across desktops, tablets, and smartphones.
- [x] **Performance Focused** – Clean, semantic HTML, lightweight styling, and lightning-fast server responses.

## 🛠️ Tech Stack

- **Backend:** Pure PHP (Vanilla PHP)
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Version Control:** Git & GitHub
